## テストケース一覧

### TC-A1a — 子プロセスで SKIP 行が 2 本出る（AC-1）

| 項目 | 内容 |
|------|------|
| 入力 | `PG_T26_NO_RECURSE=1 sh tests/extras/ta-26-plugin-sync.sh </dev/null` |
| 判定コマンド | `grep -cE '\[SKIP\] (TC-20〜TC-25\|TC-26〜TC-36)'` → **2** |
| 期待出力 | 上記が **2**。rc=0 |
| 種別 | Integration |
| 備考 | **`grep -c '\[SKIP\]'` で総数を数えないこと**（C-1 再レビュー B-5）。現行 tree には既に `[SKIP]` が **2 本**（TC-03/04 と TC-13）あり、ゲート適用後は **4 本**になる。総数で判定すると誤 FAIL する。**新規 2 本を名指しする式に固定**する |

### TC-A1b — 子プロセスでゲート対象 TC が 1 件も実行されない（AC-1）

| 項目 | 内容 |
|------|------|
| 入力 | 上記出力を `grep -cE '\[(PASS\|FAIL)\] TC-(2[0-9]\|3[24568])'` ではなく、**下記の正しい ERE** で数える |
| 判定コマンド | `grep -cE '\[(PASS\|FAIL)\] TC-(2[0-9]\|32\|34\|35\|36)'` → **ERE 内でパイプをエスケープしないこと**（下記備考） |
| 期待出力 | **0 件** |
| 種別 | Integration |
| 備考 | **C-1 が初版の欠陥を検出**: `grep -cE '\[(PASS\|FAIL)\] TC-(2[0-9]\|3[0-4])'` は (a) `\|` が literal pipe になり**常に 0**（空振り fixture）、(b) 意図した ERE に直すと**ゲート外の TC-30 / TC-33 を拾って**期待値 0 と不一致、の二重欠陥だった。ゲート対象は **20-29 / 32 / 34 / 35 / 36** であり **30・33 を含めない** |
