## 3. 「Human C-4」の定義（本 PR で確定）

**問題**: exit criteria の「Human C-4」が **merge 操作**を指すのか **第三者の approving review** を指すのかで判定が割れる。実測では 3 PR とも author = mergedBy、approving review 0 件。

**確定した定義**: **Human C-4 = Human による merge 操作**。独立性は**別項目（Independence Level I1 以上のレビュー artifact）で担保**する。

**理由**: 本リポジトリは 1 人運用で、第三者 approving review は構造的に不可能。承認の主体ではなく**レビューの独立性**で品質を担保する設計に寄せる。第三者承認を要求する定義を採ると、Phase 0 / 0.1 は**永久に完了できない**。

**この定義の限界**（残存リスクとして明記）: merge 操作者と PR 作成者が同一である以上、「第三者が内容を承認した」ことは保証されない。担保は I1 レビュー artifact の側にのみ存在する。
