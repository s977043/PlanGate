# Security Policy

## Supported Versions

This repository is maintained from the default branch. Please test against `main` before reporting a security issue.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability.

**Preferred method:** Use GitHub's private vulnerability reporting:
[https://github.com/s977043/plangate/security/advisories/new](https://github.com/s977043/plangate/security/advisories/new)

Include:

- A concise description of the vulnerability.
- Steps to reproduce or a proof of concept.
- The potential impact.
- Any known mitigations or affected versions.

We will acknowledge reports as soon as possible, investigate, and coordinate a fix before public disclosure.
